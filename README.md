# Making Health Make Sense — Closing the Gap in Healthcare

Static website for Dr. Thaddeus Bell's nonprofit, Closing the Gap in Health Care, Inc.

- Plain HTML/CSS, no build step. Each page is a self-contained `.html` file.
- `img/` holds web-sized photos.
- Deployed on Vercel (`vercel.json` enables clean URLs, e.g. `/about`).

Forms (newsletter, booking request) are preview-only and not yet connected to a backend.
